# 📊 Sales Analytics Dashboard

An interactive sales analytics project built with Python and Streamlit to explore sales performance and present business insights.

## 🎯 Project Objectives

- Analyse sales performance.
- Explore revenue trends.
- Compare sales across categories or products when available.
- Present important business metrics through charts.
- Practise data analysis and dashboard development.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly (if used in the application)

## 📂 Project Structure

- `app.py` — Main dashboard application.
- `requirements.txt` — Python package dependencies.
- Sales dataset — Add the dataset file here if your application requires one.

## ▶️ Run the Project Locally

First, install the required packages:

```bash
pip install -r requirements.txt
```

Then start the dashboard:

```bash
streamlit run app.py
```
